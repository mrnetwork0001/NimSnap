# 📸 NimSnap — Nimiq Mini Apps Competition Skill & Execution Guide

Use this skill whenever working on, reviewing, or developing **NimSnap** — the Pay-Per-Shot AI Photo Studio & Avatar Mini App for the Nimiq Mini Apps Competition.

## 📌 Project Overview & Prize Targets
- **Target Event:** Nimiq Mini Apps Competition (Cycle II)
- **Submission Deadline:** September 18, 2026
- **Prize Target:** 1st Place ($10,000 USDT)
- **Core Tech Stack:** Nimiq Pay Web SDK + Next.js 14 + Tailwind CSS + FastAPI / Replicate AI

## 🏗️ Technical Architecture Rules

### 1. Nimiq Pay Integration
- Must support instant $0.10 micro-payments in NIM or USDT via Nimiq Pay Web SDK.

### 2. Mobile-First Experience
- Design for mobile screens first: touch camera input, swipeable style presets, and side-by-side before/after image sliders.

### 3. Fast AI Processing Pipeline
- Process AI image transformations in under 5 seconds with instant downloadable result.

## 🚨 Submission Checklist
- Public GitHub repo under OSI-approved license (Apache 2.0 / MIT).
- Live demo URL supporting Nimiq Pay.
- Nimiq wallet for payouts.
- `README.md` with setup instructions & payment flow documentation.
